# Wine Labs Kiro Power

Research wine identities, prices, auctions and merchant offers using Wine Labs market intelligence.

## Install

In Kiro, open **Powers → Add Custom Power → Import power from GitHub**, enter the repository URL and select the `kiro-power` folder if prompted. To import locally, clone the repository and select that folder using **Import power from a folder**. The power connects to the hosted MCP service; it does not run a local server.

Sign in with a Wine Labs account using the browser OAuth flow. Available data and operations depend on the account, plan and credits.

After connecting, start a Kiro conversation about wine-labs and approve the relevant tool call. Access and billing follow the service's terms.
